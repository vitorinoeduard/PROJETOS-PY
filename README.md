# 🐍 Estudos e Projetos em Python

Repositório dedicado ao registro diário de códigos, exercícios práticos e projetos desenvolvidos ao longo de uma jornada intensiva de 30 dias em Desenvolvimento Back-end com Python, aplicando as convenções da PEP 8 e controle de versão com Git.

---

## 📅 Visão Geral da Jornada

| Semana | Foco de Estudos | Entregável | Status |
| :--- | :--- | :--- | :---: |
| **Semana 1** | Lógica de Programação com Python e Git/GitHub | Ferramenta CLI em Python | 🟡 Em andamento |
| **Semana 2** | Automação, Manipulação de Arquivos e Relatórios (`pandas`, `openpyxl`, `reportlab`) | Pipeline de Dados e PDF | ⚪ Planejado |
| **Semana 3** | Banco de Dados Relacional e SQL (`sqlite3`) | Camada de Persistência SQL | ⚪ Planejado |
| **Semana 4** | Consumo de APIs (`requests`) e Integração com IA | Aplicação Back-end com LLM | ⚪ Planejado |

## 🚀 Como Executar

Para executar os scripts desenvolvidos em cada etapa, navegue pelo terminal até o diretório diário desejado e execute o arquivo correspondente:

```bash
# Acessar o diretório do dia
cd semana-01/dia-01

# Executar o script Python
python diagnostico_sistema.py
```
